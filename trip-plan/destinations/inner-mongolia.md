# 内蒙草原环线 Playbook

> 北京出发 5 天经典草原环线:乌兰布统(草原三件套) → 达达线 + 热阿线(中国最美草原公路) → 99 号公路 → 锡林浩特那达慕 → 多伦 + 玉龙沙湖返程。全程顺时针,不走回头路。

## 概要

**核心吸引力**:
- **达达线 + 热阿线**:公认「中国最美草原公路」,达里湖起点的火山地貌 + 黄岗梁盘山公路
- **99 号公路**:西乌旗草原新主线(2026-07 v5 升级为正式主线),半拉山观景台为标志中点
- **乌兰布统**:影视基地日落 / 公主湖 / 将军泡子,欧式草原 + 摄影圣地
- **那达慕**:7 月底-8 月初锡林浩特那达慕周,草原盛会

**适合**:5 天 / 自驾 / 草原风光爱好者 / 摄影 / 亲子(乌兰布统段轻松)

**不适合**:纯城市游 / 非自驾(景点间距离大,公共交通不便) / 追求奢华住宿(草原深处以民宿牧户为主)

## 专属规则(LLM 必读)

- **午餐硬约束**:D3 达达线午餐必须在**巴彦查干苏木**(12:00),⚠️ 之后整段无正经餐馆;D4 午餐在西乌旗(99 号公路东端)
- **日落重头戏**:D1 影视基地 18:30 / D2 将军泡子 17:30,必须排进当日且留足拍照时间
- **必去点权重**:达达线 1.0 / 热阿线黄岗梁 0.9 / 99 号公路 0.9(v5 主线) / 乌兰布统影视基地 0.8 / 达里湖北岸 0.7
- **省钱点**:阿斯哈图石林**南门驿站免费远眺**,省 ¥160 门票(不进景区);达里湖南岸鸟岛可远观
- **那达慕涨价**:7 月底-8 月初那达慕周,锡林浩特住宿涨至 5 倍,必须提前订
- **可选温泉**:热水塘镇温泉 D3 傍晚 / D4 早起二选一,硫磺温泉解乏
- **疲劳管理**:D1 480km / D5 500km 都是长驾驶日,每 2h 服务区休整 15min(密云服务区 60km 处第一次)
- **季节**:草原 6 月返青、7-8 月金莲花盛开、9 月金秋;早晚温差大需外套
